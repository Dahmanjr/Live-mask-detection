😷 Real-Time Face Mask Detection

A Computer Vision project that detects whether people are wearing face masks in real time using YOLO, OpenCV, and Python.

🚀 Features
😷 Detects With Mask
🚫 Detects Without Mask
👤 Tracks each person with a unique ID
📊 Shows confidence score
📝 Automatically saves detection results
📁 Generates an Excel report
🛠️ Technologies
Python
YOLO
OpenCV
Object Tracking
Excel / OpenPyXL
📊 Excel Report

The system automatically records:

Date
Time
Face ID
Mask Status
Confidence Score
Notes
⚙️ How It Works
Video / Camera
      ↓
YOLO Detection
      ↓
Mask Classification
      ↓
Face Tracking
      ↓
Event Logging
      ↓
Excel Report
🎯 Purpose

This project demonstrates how AI and Computer Vision can be used for real-time monitoring and automated compliance reporting.
